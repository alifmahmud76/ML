Algorithm Analysis & Research Insights

1. Why Linear Regression vs. Logistic Regression?

Standard Linear Regression models linear continuous outputs. When applied to 22 mutually exclusive crop categories via multi-output indicators, it struggles with complex overlapping nutrient thresholds, reaching 72.95%. In contrast, Logistic Regression (97.27%) utilizes the multinomial softmax link function, which models individual class probabilities and cleanly separates agricultural categories.

2. High Performance of KNN & Support Vector Machine (SVM)

Agricultural crop conditions naturally cluster in feature space (e.g. rice requires high rainfall, banana requires high potassium). KNN (97.95%) effectively identifies the nearest historical soil profiles. SVM with an RBF kernel (98.64%) projects features into high-dimensional space, drawing maximum-margin non-linear decision boundaries that exactly mirror the paper's 98.64% benchmark.
